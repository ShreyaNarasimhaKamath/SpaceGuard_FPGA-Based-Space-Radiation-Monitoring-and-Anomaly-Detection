          <p><br /></p>
          <p>ViRBO (Virtual Radiation Belt Observatory) is one of the domain-specific virtual observatories in the NASA Heliophysics Data Environment<sup>[1]</sup> program. ViRBO provides access to metadata, data, visualizations, and services related to Earth's radiation belt. ViRBO also hosts web pages and presentation documents associated with radiation belt-related science meetings and workshops - see the <a href="/Resources/Science#Meetings" title="Resources/Science">Science Meetings list</a> for more information.</p>
          <div style="background-color:yellow">
            The ViRBO project was discontinued in 2014 and these pages are no longer being updated. Feel free to contact <a href="/cdn-cgi/l/email-protection" class="__cf_email__" data-cfemail="d5a7a2b0bcb2b0b995b2b8a0fbb0b1a0">[email&#160;protected]</a> if any links to information that you are interested in are broken.

          <h1><span class="mw-headline">1. News</span></h1>
          <ul>
            <li>New reconstruction of solar wind parameters (Bz, By, and dynamic pressure P) in the gaps of missing data in OMNI dataset for 1984-1995 time interval <a href="/ftp/users/kondrashov/SolarWind_WithDate_v2" class="external autonumber" title="https://virbo.org/ftp/users/kondrashov/SolarWind_WithDate_v2" rel="nofollow">[2]</a>.</li>
            <li>Van Allen Probes data available on CDAWeb: http://cdaweb.gsfc.nasa.gov/misc/NotesR.html</li>
            <li>Two new methods of visualizing data
              <ol>
                <li>Browse and interact with a comprehensive suite of bookmarks developed by ViRBO for the Autoplot application <a href="/autoplot" class="external autonumber" title="https://virbo.org/autoplot" rel="nofollow">[3]</a>.</li>
                <li>Browse pre-generated images of heliophysics data using ViRBO's ViViz tool [4].</li>
              </ol>
            </li>
            <li>Reprocessed CRESS data provided to ViRBO by Ali and Elkington at LASP <a href="/ftp/users/ali" class="external autonumber" title="https://virbo.org/ftp/users/ali" rel="nofollow">[5]</a>.</li>
